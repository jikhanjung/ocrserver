# 056 nginx: /i2m/ → Image2Model demo page

- User request: put the Image2Model photo → 3-D page on this server.
- The page runs in its own container `i2m-web` on `ocrserver_default` (started from the image2model checkout,
  `web/run_container.sh`; not part of this compose file, CPU only, no GPU use). A host process was tried first, but the
  host firewall drops container → host connections, so nginx reaches it by name.
- `nginx.llm.conf`, `nginx.ocr.conf`: `location /i2m/` (prefix stripped, `client_max_body_size 32m`, read timeout
  120 s) via a variable upstream (`set $i2m`), so nginx starts and reloads even when `i2m-web` is absent (502 then).
  `location = /i2m` redirects to `/i2m/`.
- Deployed 2026-11-24 01:57 UTC: both files copied to /srv/ocrserver, live `nginx.conf` = `nginx.llm.conf` (current
  mode), `nginx -t` + reload. Checked: `/healthz` unchanged (wrapper 0.3.17), `/i2m/healthz` ok, `/i2m/predict` ok.
- The dev `nginx.conf` here is an old OCR-mode copy and was not changed (the mode scripts overwrite the live one).
