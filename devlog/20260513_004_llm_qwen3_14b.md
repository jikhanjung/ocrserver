# 20260513_004 — Qwen3-14B LLM 연동 및 GPU 모드 전환

## 작업 내용

### 1. LLM 서비스 추가 (GPU 1)

`docker-compose.yml`에 `llm` 서비스 추가.
- 이미지: `vllm/vllm-openai:latest`
- 모델: `Qwen/Qwen3-14B`
- GPU: device_ids `['1']`
- Docker Compose profile: `llm` (선택적 기동)

nginx `/llm/` 경로로 라우팅:
```nginx
location /llm/ {
    proxy_pass http://llm:8000/;
    proxy_read_timeout 300s;
}
```

경로 rewrite 방식: `proxy_pass http://llm:8000/;` — trailing slash로 prefix 자동 제거.  
`/llm/v1/chat/completions` → `http://llm:8000/v1/chat/completions`

### 2. GPU 1 모드 전환

Docker Compose profiles로 GPU 1을 OCR 또는 LLM 용도로 전환:

- `profiles: [ocr]` — chandra-b (두 번째 OCR 인스턴스)
- `profiles: [llm]` — llm (Qwen3-14B)

모드 전환 스크립트:
- `mode-llm.sh`: chandra-b 중지 → llm 기동 → OCR_CONCURRENCY=6
- `mode-ocr.sh`: llm 중지 → chandra-b 기동 → OCR_CONCURRENCY=12

### 3. KOPRI SSL 처리

vLLM 컨테이너가 HuggingFace에서 모델을 다운로드할 때 KOPRI CA의 SSL MITM으로
인증서 오류 발생. 호스트 CA 번들 마운트로 해결:

```yaml
volumes:
  - /etc/ssl/certs/ca-certificates.crt:/etc/ssl/certs/ca-certificates.crt:ro
```

### 4. --enforce-eager 추가

**문제**: Turing CC 7.5 (RTX 8000)에서 CUDA 그래프 컴파일(Torch Inductor)이
51개 캡처 사이즈에 대해 1~2시간 소요. 53분간 로그 없이 GPU 사용률 0%.

**원인**: vLLM v0.20.2 기본 설정이 `VLLM_COMPILE` 모드 + Inductor 백엔드로
GPU-specific CUDA 그래프를 컴파일함. 캐시 없는 첫 실행 시 CC 7.5에서 매우 느림.

**해결**: `--enforce-eager` 옵션으로 CUDA 그래프 컴파일 건너뜀.
- 기동 시간: 1~2시간 → 수 분
- 처리량 영향: 약 10~15% 토큰/초 감소. Qwen3-14B 규모에서 실용상 무시 가능.

### 5. nginx DNS 캐싱 문제

**문제**: `--enforce-eager`로 컨테이너를 재생성하자 `/llm/health`가 502 반환.

**원인**: nginx가 `proxy_pass http://llm:8000/`의 IP를 설정 로드 시점에 캐시.
컨테이너 재생성으로 IP 변경(`172.18.0.4` → `172.18.0.3`)됐으나 nginx는 구 IP로 요청.

**해결**: `nginx -s reload`로 DNS 재분석. mode-llm.sh / mode-ocr.sh에 자동 포함.

구조적 해결 방안 (향후 필요 시):
```nginx
resolver 127.0.0.11 valid=30s;
set $llm_upstream http://llm:8000;
proxy_pass $llm_upstream/;
```

## 트러블슈팅

| 증상 | 원인 | 조치 |
|---|---|---|
| `/llm/health` → 502 | nginx DNS 캐시 stale | `docker compose exec nginx nginx -s reload` |
| LLM 컨테이너 수십 분째 health: starting | CUDA 그래프 컴파일 중 | `--enforce-eager` 추가 후 재시작 |
| HF 다운로드 SSL 오류 | KOPRI CA MITM | 호스트 CA 번들 볼륨 마운트 |
